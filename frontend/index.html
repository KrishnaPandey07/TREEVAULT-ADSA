TreeVault

Ever wondered how your data stays organized?

This app stores student records inside a real AVL Tree — a data structure that automatically keeps itself balanced so every search is lightning fast.

Without balancing

If you add students 10, 20, 30, 40 in order, a normal tree becomes a straight line. Finding the last student means checking every single one.

Slow. 4 students = 4 steps to find the last one.

With AVL balancing

An AVL Tree rearranges itself automatically. Same 4 students, but now the tree is short and wide — finding anyone takes at most 2 steps.

Fast. Even with a million students, max ~20 steps.

The tree checks two things after every change

That's it. Two simple rules keep the entire tree balanced.

1

Height

Every node knows how tall its left and right branches are. A leaf has height 1. A parent's height = 1 + the taller child.

2

Balance Factor

Take the left branch height, subtract the right branch height. If the answer is -1, 0, or +1 — the node is fine. If it's anything else, the tree fixes it immediately.

How does it fix itself? Rotations.

When a node gets too heavy on one side, the tree swaps a few pointers to redistribute the weight. There are 4 possible patterns:

LL Left side too heavy → rotate right
RR Right side too heavy → rotate left
LR Left-right zigzag → double rotation
RL Right-left zigzag → double rotation
